# Glossary

- **[[Event]]**: something in the game that makes a sound; files plus
  settings, played by path.
- **[[Event path]]**: folders and name of an event, `combat/hit`; what the
  code writes.
- **Take**: one of an event's [[Sound files|sound files]], interchangeable
  with the others.
- **Pick**: how a play chooses a take: `shuffle` or `random`.
- **Jitter**: the random change of pitch or volume on each play
  ([[Settings]]).
- **Cooldown**: the minimum time between two plays of the same event.
- **[[Groups|Group]]**: a set of events sharing a volume, such as `ui` or
  `ambience`.
- **Voice**: one sound playing at a time; the [[Runtime]] has a fixed number.
- **[[Runtime]]**: the code in the game that plays events.
- **[[Tool]]**: the Tuning Fork application.
- **[[Hot reload]]**: a running game picking up saved changes when its window
  regains focus.
