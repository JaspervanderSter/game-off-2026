Sound effects

Try the game and listen to its transformations, attacks and interface sounds. A friendly blessing and an enemy hex should feel different; repeated effects should stay readable when several creatures act at once.

There are two ways to work with the game's sounds:

With Tuning Fork, without Godot

Download ShapeshiftersDuel-Windows.zip and TuningFork-Windows.zip from the itch.io download section. Extract both archives.

Open Tuning Fork and select the extracted game folder containing ShapeshiftersDuel.exe and tuning_fork.json. The SFX and Music tabs automatically open custom/sfx/ and custom/music/. Replace or tune an existing sound or track, save, then return to the running Windows game to hear the change.

With the Godot project

Get the repository on GitHub, then open prototypes/prototype_02/project.godot in Godot 4.7 and run the game.

You can use Tuning Fork with this version too: open the prototypes/prototype_02/ folder. In the game, use Ctrl+Shift+M on Windows and select Custom to hear these edits; a fresh editor run starts in Default. Saved sounds and music reload when you return to the game window.

Use the Windows download or the Godot project to test local sound changes. The browser game on itch.io does not reload files from your computer.

A fresh Windows build starts in Custom. If you previously selected Default, use Ctrl+Shift+M in the game to switch back; the choice is remembered. Tuning Fork has no mode selector.

To share a sound proposal, send the changed files and JSON settings from custom/sfx/ or custom/music/, with a short note about what you changed. If you create a new event, tell me when it should play so I can connect it to the game.

Music

Use Tuning Fork's Music tab to replace and tune the preparation and combat tracks, or the complete world map ambience. It discovers OGG/WAV recordings automatically, including newly added files, and lets you edit their settings, preview transitions and define playback segments.

A reference or a short demo is a good starting point. Think about the contrast between planning a team and watching a chaotic magical fight, while leaving room for the sound effects.

Save your changes and return to the running game in Custom mode to hear them. The map reference covers a full 160-second day/night cycle. See the music workflow and ambience reference in the complete guide.

You can also propose a reference or demo without installing the tool. Loops, transitions and the amount of music to make can be discussed together.
