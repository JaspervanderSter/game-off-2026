Audio contributor handbook

Tuning Fork: complete guide

Replace and tune sound effects, music and world map ambience, then hear your work in Shapeshifter Duel without rebuilding the game.

New here? Start with the five-step quick start. This guide explains the full workflow and the settings you will use along the way.

1. Download and open the project

  1. Download ShapeshiftersDuel-Windows.zip and TuningFork-Windows.zip from itch.io. Extract both archives fully.
  2. Start ShapeshiftersDuel.exe and TuningFork.exe. Keep the files supplied beside each executable, including Tuning Fork's WAV encoder.
  3. In Tuning Fork, choose the game from the project list or use Open a game folder. Select the folder containing the game executable and tuning_fork.json.
  4. Choose SFX or Music. The game configuration automatically opens custom/sfx/ and custom/music/; there is no folder or Default / Custom selector inside Tuning Fork.

A fresh Windows game starts in Custom. If you have changed that preference before, press Ctrl+Shift+M in the game and select Custom. The game remembers this choice across restarts. Default plays the original audio, including the procedural map ambience.

With a source checkout, open prototypes/prototype_02/ in Tuning Fork and run its project.godot in Godot 4.7. On Windows, select Custom in the game: editor runs start in Default when no preference exists.

Use the Windows game or a Windows editor run for local audio iteration. The itch.io browser game cannot load your local changes.

2. Edit sound effects

An event is a named sound the game can trigger. In SFX, filter the list by path, then select an existing event. Its description explains its purpose. Changing an existing event is the quickest way to hear your contribution in context.

Files and preview

Each waveform card is a take. Click a card to audition that file, or use Play, Space or a double-click on an event to hear its normal playback rules. Auto-play previews slider changes. Stop or Esc ends a looping preview.

Drop WAV or OGG files into the SFX window, or use the add-file card, to add takes to the selected event. WAV is converted to OGG. Adding a take keeps the existing takes: to replace the sound completely, remove the unwanted files with their bin buttons too. File operations take effect on disk immediately; back up files before replacing them.

Settings you can tune

Volume / volume jitter
Set the level in decibels and the random variation around it. Start with small changes and compare against nearby events.
Pitch / pitch jitter
Set playback speed and pitch, with optional random variation. A pitch of 1 preserves the recording; 2 plays an octave higher and twice as fast.
Cooldown
The minimum delay in milliseconds between plays of this event. Triggers inside the delay are skipped.
Pick / shuffle refill
Random chooses a take on each play; shuffle deals through a pool. Refill controls when that pool resets; 0 uses all takes.
Loop
Repeat until stopped. Variation and repeat-delay controls that do not apply to loops are disabled.
Protected
Give the event a voice that other sounds cannot steal.
Group
Choose the mixing group. Its volume also affects the preview.
Files from
Borrow another event's takes while keeping this event's own settings. Follow the displayed link to edit the original takes.

Hover settings for tooltips and use a reset arrow to restore that setting's default. A warning colour can indicate missing or unreadable files, unknown settings or an unknown group.

Create, rename or remove an event

The plus button beside the filter creates an event with a folder, name and description. The pencil renames or moves it; the bin removes it and its files, unless another event borrows them. Creating or renaming an event changes its path: a programmer must connect that path to the game before it will trigger there. Adding a file alone does not create a new gameplay trigger.

3. Mixing groups

Open Groups at the end of the SFX list to adjust the level of a whole family of events. You can add a group, rename one and remove unused groups. Events follow a renamed group.

Balance individual events first, then adjust their shared group. Tuning Fork previews the saved group volume; additional volume changes made by game code can still make the in-game result differ.

4. Edit music and transitions

The Music tab discovers every OGG/WAV recording recursively under the project's configured music folder. Tracks are not a fixed list. Select a recording to see its waveform, seek through it, preview it and edit its settings. A JSON file with the same basename stores those settings; Save creates it if it does not exist yet.

Use Replace audio to change a selected OGG track while retaining its path and bindings, or Import music (WAV / OGG) to add a track. Imports convert WAV to OGG. For an existing WAV track, overwrite it with another WAV in your audio editor, or import a new OGG and update the binding. New files appear automatically.

Volume
The recording's level in decibels.
Fade seconds
Full fade-in and fade-out duration. Use a positive value.
Loop
Repeat the whole recording or selected segment. Turn it off for one playback.
Playback mode
Continuous keeps position, including while ducked behind another phase. Restart starts at the beginning on entry. Segments chooses a defined region on each entry, avoiding an immediate repeat when alternatives exist.
Duck dB
How much a continuous outgoing track is reduced while another phase is active. A value of -40 makes it very quiet.
Frenzy speed per level
Optional playback speed increase driven by the game's frenzy level. Use 0 to preserve the musical speed and pitch.
Segments
Add regions with start and end times in seconds before selecting Segments mode. Each must have positive duration and fit inside the recording. Loop determines whether the chosen region repeats.

Connect tracks to game phases

Select workspace.json in the Music list. For this game, prep, battle and ambience name tracks by path relative to custom/music/. Change a binding to use an imported track. Keep sfx_directory pointing at the intended SFX folder, relative to the game folder.

Configuration buttons for recognised track bindings preview transitions: try Prep, then Battle, then Prep again to compare fades and continuous playback. Save the edited track settings before comparing the saved transition preview. Tuning Fork discovers these bindings from configuration; the game's phase names are not hardcoded into the tool.

Track preview helps you hear playback and fades. Test in the game to judge the mix with SFX, the sky cycle and frenzy progression.

5. World map ambience

custom/music/world_map_cycle.ogg is a full recorded reference of the procedural map ambience. Replace the complete mix freely; its birds, winds and individual timings are starting points, not requirements.

  • 0 s: day.
  • 40 s: golden mist.
  • 80 s: dusk.
  • 120 s: night.
  • 160 s: day again; the loop restarts.

These are sky palette anchors with blended transitions between them. The game aligns this recording with the sky clock when entering the map and stops it outside the map. Make a seamless 160-second replacement to keep your intended speed and pitch: a different duration is fitted to the visual cycle by changing playback speed.

The recording replaces procedural ambience in Custom mode. Default and the Web game keep the procedural version. Tuning Fork edits recordings and their playback settings; baking a new procedural generator remains a separate game-specific task.

6. Save and test in the game

  1. Preview the event or track and adjust its settings.
  2. Use Save or Ctrl+S for the selection; Ctrl+Shift+S saves all pending edits.
  3. Return focus to the running game in Custom mode. Saved SFX, music files and settings reload without a new build.
  4. Trigger the relevant event, enter its phase or return to the map. Compare levels and transitions in context.

A looping SFX already playing takes new settings on its next start. New event paths still need game integration. Revert restores settings from disk; it does not undo a recording that you have already replaced on disk.

Files changed in an external audio editor also reload in Tuning Fork. If an external JSON change conflicts with unsaved edits, the tool keeps your edits and asks you to Save or Revert. Resolve the conflict deliberately before continuing.

7. Share your changes

Send the changed recordings and JSON settings from custom/sfx/ and custom/music/, retaining their relative paths. Include workspace.json if you changed track bindings, and groups.json if you changed mixing groups. With Git, commit those same source files.

Add a brief note saying what to listen for and where to trigger it. For a new or renamed event, give its exact path and intended trigger. Keep a backup before extracting a later build over your edited game folder.

8. Troubleshooting

I cannot find my game
Extract the archive first, then open the folder containing the game executable and tuning_fork.json. Do not select the ZIP, Tuning Fork's own folder or the custom/ subfolder.
Preview changed; the game did not
Save, return focus to the Windows game, check Custom in its Ctrl+Shift+M dialog, then trigger the sound again. For music, check the binding in workspace.json. Local edits cannot be heard in the browser game.
A new file never plays
An imported music track needs a phase binding. A new SFX event needs a gameplay trigger connected by the programmer.
WAV import fails
Keep the packaged oggenc.exe beside Tuning Fork. Read the error message and try a valid OGG export from your audio editor.
Music cannot be saved or previewed
Check that the recording is readable and every segment ends within its duration. After replacing a track with a shorter one, update its segments.
Map audio sounds sped up
Use a 160-second replacement for the full ambience loop. The game fits other durations to the sky cycle.

For the exported game's reference, read AUDIO_WORKSPACE.md beside its executable. For the tool's definition and integration details, see the Tuning Fork documentation.
