Tuning Fork

Create the sounds of a game and tune them while it runs. Five steps to get going; hover any button or setting in the tool for the rest.

Download the Windows game and Tuning Fork from itch.io, then extract both archives. This guide also works with the Godot project.

  1. Open the game

    Start TuningFork.exe and pick the game in the list, or Open a game folder: the folder that holds sfx/. The folder button at the top brings you back to this list.

  2. Choose a sound

    An event is one sound of the game, such as combat/hit. Choose an existing event to change a current sound. To add a new one, click beside the filter, give it a folder, a name and when it plays. Tell me when a new event should play so I can connect it to the game.

  3. Add sound files

    Drop WAV or OGG files on the window. Each file is a take; with several, the game can vary repeated sounds by picking between the takes.

  4. Listen and tune

    or Space plays the event as the game will. Move the sliders; with auto-play on, it replays after each change. Esc stops a looping sound.

  5. Save and hear it in the game

    or Ctrl+S saves the event, Ctrl+Shift+S saves everything. Keep the game running: click back into it and the next play uses your change.

Keep oggenc.exe beside TuningFork.exe: it converts dropped WAV files to OGG. Mixing groups (effects, ui, ambience…) are the last entry of the event list.
